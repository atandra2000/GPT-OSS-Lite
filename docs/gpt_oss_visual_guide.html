Model Architecture 🏛️

12-layer transformer backbone showing alternating sliding-window and full self-attention blocks, one Attention+MoE composite repeated 12 times. Global YaRN disables 24 of 48 frequency pairs, not 25%. Decode stores rotated K and unchanged V.

Data Pipeline ⚡

Declared 8B-token recipe, shared packing and mmap-backed windows. EOS 128009 exceeds the configured 128000 embedding rows. This integration gap is unresolved, not a working producer-to-model handoff.

Training Workflow 🔄

Pure PyTorch pretraining loop featuring mixed-precision BF16 forward pass, auxiliary load-balancing loss, CE before the finite-loss gate, four-micro-batch accumulation and optimizer-clock checkpoints. Final save adds RNG separately. Neither periodic nor final saves capture sampler position. Five nonfinite losses restore the latest checkpoint or abort when none exists.

Optimization Stack 🚀
